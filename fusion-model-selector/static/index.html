Cloud routing & billing details

Cloud data disclosure: Your prompt is sent to OpenAI for architecture by default; selecting Claude instead sends it to Anthropic. When automatic architect fallback is enabled, a failed OpenAI architect sends the same prompt to the selected verified Claude model once, adding API cost and latency. Claude architecture is then shared with the selected builder and OpenAI synthesis/analysis. If you select Grok / xAI as builder, your prompt and architecture are also sent to xAI; separate xAI billing applies. Your prompt, architecture, and builder output are then sent to OpenAI for synthesis. The fourth Reasoning / Divergence stage sends your prompt and all prior outputs (architecture, builder, synthesis) to OpenAI using the synthesis model, adding API cost and latency. OpenAI usage may cost money. Ollama building runs locally. Do not submit secrets. API keys stay server-side; outputs are not executed.

Grok documented IDs shown as unverified are not installed or confirmed accessible and are not ready until a valid server-side xAI key verifies the catalog. An invalid key cannot enable them. Catalog verification does not guarantee generation access or credits.

Perplexity cloud Builder: Selecting Perplexity sends your prompt and architecture to Perplexity with web search enabled. Separate API billing and web search fees apply; a consumer subscription does not include API access. Its answer and sources are sent onward to OpenAI synthesis and the fourth analysis stage. Only the documented Perplexity Sonar model is offered, not third-party models or presets. An unverified choice stays disabled until authenticated catalog access succeeds; credits and generation access remain untested.
